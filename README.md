# C Programming Practice Repository

Welcome to my C programming practice repository.  
This repository contains simple beginner-friendly C programs created while learning loops, conditions, and number operations.

---

## 📂 Programs Included

### 🔤 Alphabet Skipper
Prints alphabets using a skipping pattern.

### 🔢 Digit Counter
Counts total digits present in a number.

### ➕ Digit Addition
Calculates the sum of digits of a given number.
